Privacy Policy

Application: Hermes  ·  Last updated: 14 September 2026

What Hermes is

Hermes is a private, personal automation tool operated by a single individual (the "Operator") on their own computer. It is not a public product, has no sign-up, and is not offered to other users. It connects to the Operator's own Google Account so the Operator can read and manage their own mail, calendar, files and documents through their own tooling.

Google user data accessed

With the Operator's explicit consent, Hermes may access the following data from the Operator's own Google Account, limited to the scopes granted at authorization time:

  • Gmail — read messages, send messages, and manage labels on the Operator's own mailbox.
  • Google Calendar — read and create events on the Operator's own calendars.
  • Google Drive — read, upload and manage files in the Operator's own Drive.
  • Google Sheets and Docs — read and edit spreadsheets and documents owned by the Operator.
  • Contacts — read the Operator's own contacts.

Only scopes required for a requested action are requested, and access can be revoked at any time as described below.

How data is used and stored

  • All processing happens locally on the Operator's own computer. There is no Hermes server, no cloud backend, and no third party receiving data.
  • An OAuth token is stored locally on the Operator's machine so the tool can act on the Operator's behalf without repeated sign-ins. It is not transmitted anywhere else.
  • Message and file content is read only to perform the action the Operator requested, and is not retained beyond the local session or cache needed for that action.
  • Data is never sold, rented, or shared with advertisers, data brokers, or any other party.
  • Data is not used to train or improve machine-learning models, and is not used for advertising or creditworthiness purposes.

Limited Use disclosure

Hermes's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the locally stored token, after which Hermes can no longer reach any Google data. Revocation, or deleting the local google_token.json file, removes all stored credentials.

Security

Credentials and OAuth client secrets are kept in files on the Operator's own machine, protected by the operating system's user account permissions. No credentials are embedded in this website or published anywhere.

Changes to this policy

Any change will be published on this page with an updated revision date. The current version always governs use of the application.
